In this Assignment I am supposed to create a simple Recipe Collection to train basic referrencing and building of a Website based on the central Home Page to Navigate across different Recipes.

As I did not yet Read the requirements of this Assignment the following subjects are what I expected to apply:

* Referring across Directories

After reading the Instructions this seems to be exactly what is expected so let's get to work ...
